# 1.6.6 需求：Gemini 详情直接显示其他额度组、Claude 橙、概览额度条等长

用户提出两组需求：

1. Gemini 详情卡里没有直接显示的「其他额度组」要直接展示出来，位置紧接上面的主额度；中间两行内容（状态显示「最近成功 … / 缓存数据」与「其他额度组」字样）不要了，不占位置；该部分额度用量的颜色改为 Claude 的主体橙色，时间标记的蓝色不变，只改用量的颜色。
2. 概览里 ChatGPT 与 Gemini 的显示条加长到与 Command Code 一样；如果有小字重叠，则压缩或删除小字的显示内容。

## 已确认的口径（本轮实施前与用户确认）

| 决定点 | 结论 |
| --- | --- |
| 删除内容 | 删掉「最近成功 hh:mm」整行（含右侧「缓存数据」小字）与「其他额度组」折叠标题行；**保留其他组的组名标题**（如 `Claude and GPT models`）；顶部标题栏右侧状态（如「额度已更新」）保留 |
| 橙色范围 | **仅** Gemini 详情卡中非主额度组（当前唯一的一组为 `Claude and GPT models`）的用量条与「剩余 %」文字；主组 `Gemini Models`、ChatGPT 卡与概览行不改 |
| 额度分级 | 使用 Claude 橙的那部分额度只保留 20% 红档：剩余 ≥ 20% 为 Claude 橙，< 20% 为红，无有效值时为次要灰 |
| 概览小字 | 状态小字先让位：名称保持 15 pt（过长按现有规则截断），标题下方 11 pt 状态小字先缩字号，仍放不下时截断 |
| 橙色取值 | `#D97757`（Claude 品牌橙），实现为单一常量；真实界面复验后如需微调只改一处 |

## Gemini 详情卡

- 主额度组（`Gemini Models`）仍按 `5 小时` / `周额度` 两行显示，配色沿用现有红绿灯分级。
- 其他额度组直接接在主额度下方：组名标题（13 pt 半粗）+ 该组的 `5 小时` / `周额度` 两行，组与组之间、组内行之间沿用卡片既有的 12 pt 间距，不再有折叠控件与折叠状态。
- 删除折叠后不再需要「展开/收起」状态，`DetailPreferences.expandedGoogleAccounts` 与卡片的显隐不再存在。
- 该组的用量条与「剩余 %」用 Claude 橙 `#D97757`；低于 20% 用红；时间条继续用蓝，且不随用量颜色变化。
- 该组组名标题、`5 小时` / `周额度` 行标签、重置时间文字与日期保持现状（次要灰 / 13 pt / 11 pt）。
- 失败提示块保留：只有读取失败时才出现，包含失败文案与（区域不可用时的）官方说明链接。
- 卡片高度常量按「两组都显示」的实测高度更新，供详情页首选高度与空状态占位使用；只有一组时卡片按内容自然收窄（最小高度沿用既有 228 pt）。

## 概览额度条

- ChatGPT 与 Gemini 的概览行图示区从 164 pt 加宽到 224 pt，两列各 106 pt，与 Command Code 的 5H + 月额度双列行完全等长。
- Command Code 只有单列（既无月度也无周窗口）时保持 164 pt 单列；DeepSeek 余额文字行不变。
- 加宽后名称列由约 152 pt 压缩到约 92 pt：名称保持 15 pt、过长截断（悬停与无障碍文本保留全文）；标题下方的状态小字允许缩小字号，仍放不下时截断。不改变行高、拖动排序、两列间距与轨道高度。
- 不改菜单栏、不改详情卡里的 Command Code 紫色与 DeepSeek 文字口径。

## 边界

- 本轮为小版本迭代，只完成编码、自动验证、签名构建与本机安装；不发标签、不推送远端、不建 Release，除非用户明确要求。
- 不新增端点、不改变取数与节流口径，不读取认证文件、不读取浏览器会话、不向第三方发送凭证。
- 菜单栏显示、拖动排序、概览行高与各品牌详情页的取数行为保持现状。
