# Minget 1.4.0 发布说明

## 点火模型统一

- 应用内 Command Code 手动点火和定时点火统一使用 `deepseek/deepseek-v4.1-flash`。
- 外部 `minget-fire` 的 Command Code 路径已核对为同一模型；LaunchAgent 调度不在本版本修改范围内。

## 菜单栏低额度自适应刷新

- 菜单栏当前选中的 ChatGPT 账号在 5 小时剩余低于阈值，或周额度剩余低于阈值时，使用额外的低额度刷新周期。
- 菜单栏当前显示 DeepSeek 且实际显示币种为 CNY、余额低于阈值时，使用额外刷新周期。
- 默认值为启用、30 秒、5 小时 50%、周 15%、DeepSeek 15.00 元；周期和阈值均可在设置中调整。
- 切换菜单栏来源后，补充刷新只作用于新的当前来源；无效金额输入会暂停对应加速。

## 验证

513 项自动测试执行，512 通过、1 项既有 AX 环境跳过、0 失败。Release arm64 构建、staging/install/archive 严格签名、已安装签名包退出/重启，以及设置页明暗布局检查通过。

本版本没有执行真实模型请求，也没有通过人为制造额度条件触发真实低额度服务轮询；后者保留为发布后现场观察项。
