# 1.6.7 审核

审核对象：分支 `codex/minget-1-6-7` 的工作区改动（`MingetSettingsView.swift`、`ManagedAccountManagementView.swift`、`AccountManagementView.swift`、`UsagePanelView.swift`、两个测试文件、文档与版本号）。检查方式：源码差异逐项核对 + 完整 `swift test` + 五个分组明暗渲染目视 + Release 严格签名构建与安装校验。审核时间 2026-10-13。

## 检查结果

- [x] 只改视觉与层级：开关语义、`DetailPreferences` / `MenuBarPreferences` / `FireSchedulePreferences` 的键与读写路径、取数与节流、账号注册表、凭证与点火流程均未改动（差异中无相关符号）。
- [x] 唯一标题层级：页面标题只在 `paneHeader` 出现一次；分组内重复小标题（「菜单栏显示」「5 小时点火计划」「管理你的账号」）已删除；说明文字归位到所属分组的 footer，不再独占卡片。
- [x] 侧栏彩色图标：五个分组各有系统语义色，`tint` 互不相同且被测试固定；符号名在本机可解析（测试逐项断言，避免图标名拼错导致空白）；选中态沿用 `List(selection:)` 原生高亮，图标保持彩色。
- [x] 控件两列对齐：成对的标签与控件改用 `LabeledContent`；阈值行读数为「低于 N%」在前、步进器在后，符合 macOS 的数值 + 步进器次序。
- [x] 账号页：标题与主操作上移到页头，主操作只在托管模式（有账号注册表）出现，与页头说明一致；账户行保持 15 pt 半粗名称 + 11 pt 次要身份/状态与 64 pt 最小高度；未在分组卡片内嵌套卡片。
- [x] 辅助功能：`DatePicker` 与计划开关补了名称（此前只有删除按钮有）；侧栏方块对辅助功能隐藏、行保留分组名；品牌语只作为说明文字，不作为可交互元素。
- [x] 版本号回退修正：两个界面在缺少应用 Info.plist 时分别显示 `—` 与不显示版本标签，均由测试固定；正式 App 仍读自己的 Info.plist。
- [x] 测试隔离修正：`makeModel` 注入隔离的 `FireSchedulePreferences`，证据测试不再写入测试进程的标准偏好（旧测试会在多次运行后累积计划行，本次导出前已复现）。
- [x] 完整回归 694 项（Core 462 + App 232），5 项既有跳过，0 失败；新增 4 项外观测试与 1 项分组渲染导出。
- [x] 渲染证据：五个分组明暗各一张、侧栏图标两张、托管账号页与添加账号弹窗明暗各两张，全部使用合成账号与隔离 UserDefaults；离屏宿主不绘制侧栏的限制已记录，侧栏单独留证。
- [x] Release 严格签名构建通过，安装到 `/Applications/Minget.app` 后版本为 1.6.7，安装前后可执行文件哈希一致，替换前 1.6.6 已备份并校验。

## 结论

改动范围与用户确认的口径一致，功能面零改动，自动测试与渲染证据齐全；真实界面的观感验收由用户在正式安装的 1.6.7 上进行，状态记入 [ACCEPTANCE.md](ACCEPTANCE.md)。本轮未发布，回滚边界见 [ROLLBACK.md](ROLLBACK.md)。
