# 1.6.4 需求：概要页按住 Logo 拖动排序

用户已确认：概要页每行左侧 Logo 按住后可上下拖动排序，动画流畅；顺序跨平台全局混排；只持久化概要页顺序，不影响菜单栏来源、管理列表和详情页；按住稍作停留才进入拖动，短按 Logo 仍进入详情。

- 概览页（有效 Tab 为「概览」）的全部账号行可拖动排序，包括 ChatGPT、Google、DeepSeek 和 Command Code 的账号行。
- 顺序保存在本机，下次打开恢复；新增账号落到列表末尾，已移除账号自动从顺序中清理。
- 拖动期间开始的行保持跟手，其余行按一格滑让，松手落位有过渡动画；拖动进行中即使发生刷新，行序也不跳动。
- 拖动只挂在 Logo 上，短按 Logo 或行内其他位置仍进入详情。
- 键盘与 VoiceOver 可用「上移/下移」调整顺序，结果与拖动一致。
- 空状态的 Gemini 占位行不可拖动，因为它不对应真实账号。
- 不改账号注册表的正式顺序，不改菜单栏来源列表、管理账号列表和详情页标签顺序。
- 只读写本机顺序偏好，不读取认证文件、浏览器会话或额度数据；本轮不发布。
