# 1.6.3 需求：多账号添加与管理

用户已确认：四个平台支持更多独立账号；管理账号顶部、平台分组和服务详情提供添加入口；同步支持移除；新增 ChatGPT、Command Code 账号具备现有点火功能，计划默认关闭；移除菜单栏当前来源后由用户重新选择。

- 新增稳定账号注册表，现有账号 ID、CLI 目录、Keychain 条目、名称、缓存、菜单栏选择及计划迁移保留。
- Google / ChatGPT 不再限定两个账号；API 服务按账号实例保存与刷新，禁止覆盖已有连接。
- 添加时可命名，最多 40 字符；成功连接后显示卡片，连接状态与额度状态分开；取消无空记录，重复已确认身份或 Key 指纹提示已存在。
- 每个账号支持改名、重新连接、刷新、确认移除；移除先停用再清理，失败可重试，其他账号不受影响。
- 动态列表按平台和添加顺序排列，内容滚动，底部操作固定；ChatGPT、Google、DeepSeek 可独立选择为菜单栏来源。
- 新增点火不会自动执行，新增计划默认关闭，Command Code 账号间串行；既有参数及外部 LaunchAgent 不改。
- 仅沿用官方 CLI 登录和只读额度接口，不读取认证文件或浏览器会话；Key 仅保存到 Keychain。
- 完成自动验证、Release 签名、本机界面核验和备份安装。真实新账号需用户完成官方登录或输入 Key 后核对；未完成不得记为通过。
- 本轮本机交付，不推送或公开发布。

后续缺陷修正：真实新增 Google 账号被官方地区资格检查拒绝时显示明确原因；没有成功快照不得显示缓存。见 [诊断与修正](GOOGLE_ELIGIBILITY_FIX.md)。
