# v1.5.0 审核

状态：代码、完整自动测试、Release 构建、严格签名及本机备份安装已完成；设置、详情切换和账号管理窗口已有真实界面证据。菜单栏重复点击修复等待签名包用户复验；首次连接和换机验收待完成；未发布。

审核重点：切换标签不能重复发起刷新；`account/login/completed` 必须匹配当前登录 ID 与 app-server 连接代次；取消后旧通知不能更新状态；凭证只经现有 Keychain 路径；缓存与实时额度文案区分；旧版升级不触发首次引导。

差异复核：详情筛选仅读取 `DetailPreferences`，没有写入菜单栏来源或调用刷新；偏好变更时重新创建浮窗内容明确传入 `refreshOnAppear: false`。登录与额度读取共用已有 `UsageService`，完成通知需同时匹配当前登录 ID、服务代次和连接代次；取消和停止清除进行中状态。早于启动响应的完成通知由待匹配表处理，匹配后只回调一次。Key 表单复用原有 Keychain 存取和只读验证路径；连接文案区分已保存、缓存和实时数据。

用户实测指出原签名包的菜单栏第二次点击仍不关闭，而 Esc 与窗口切换正常。复核发现 `.transient` 可能在鼠标按下时先自动关窗、随后鼠标抬起触发按钮再次打开。现由 `.applicationDefined` 和明确的外部点击、Esc、应用失焦监听管理关闭，等待用户在新签名包复验。账号管理的既有缓存状态不再误写为“正在读取额度”。

`git diff --check` 无格式错误。完整测试及签名结果见 `IMPLEMENTATION_REPORT.md`。未触发点火或重置额度消耗。
