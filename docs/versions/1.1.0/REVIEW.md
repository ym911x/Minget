## 1. 独立审核结论

1. 详情页已经按用户最后确认的参考图重构为紧凑卡片布局。Codex 账号邮箱位于 Codex 卡片右侧，原始 Blossom SVG/PNG 资源后的文字来自 `account/read` 套餐字段，标题区按系统首选语言显示中文或英文名称并附版本，刷新状态进入顶部标题行，齿轮入口连接到单独设置窗口。
2. 5 小时和周额度各有一条连续额度轨道和一条时间轨道。四条轨道共享同一组三列布局，时间轨道分别使用 5 段和 7 段蓝色分段条。重置标签显示绝对本地时间；到期、未知和非法状态不伪造日期。
3. DeepSeek 与智谱 GLM 余额卡片各自占据一整行；金额从真实 `available` 或 `total` 字段取值，概览使用 Decimal 两位小数，字段标签按实际字段语义显示。DeepSeek 使用只保留 `deepseek` 的透明文字标识，金额行将“余额”置于金额左侧，官方连接与状态摘要移到金额下方并完整显示。
4. 设置页只新增用户明确要求的两项详情显示开关，默认内容移除滚动容器。连接管理、钥匙串诊断、关于、打开详情和退出均复用既有能力，没有加入刷新周期、通知、主题等新设置。
5. 显示开关写入应用自有 UserDefaults，不调用 Keychain，不断开服务，不改变后台轮询。详情窗口和设置窗口共用同一个 `UsageViewModel`。
6. 改动未触碰 Provider 端点、认证协议、凭证协调器或缓存格式。源码中未加入凭证、Cookie、Authorization 值或模型请求。
7. DeepSeek 状态读取只访问 `https://status.deepseek.com/`，不带认证头；页面不可达和标题不匹配均保留为未知状态，代码和 fixture 测试均未把失败转成正常。
