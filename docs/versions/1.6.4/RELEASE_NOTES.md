# Minget 1.6.4：概要页拖动排序

在概要页拖动账号左侧 Logo，即可调整账号顺序，支持 ChatGPT、Google / Antigravity、DeepSeek 和 Command Code 跨平台混排。按下后移动即可拖动，行跟随指针，其余行滑让，松手自动落位；短按仍进入详情。

顺序保存在本机，只影响概要页。新增账号追加到末尾，失效账号在显示时过滤；管理列表、菜单栏来源和详情页顺序保持原有规则。提供无障碍上移、下移调整入口。
