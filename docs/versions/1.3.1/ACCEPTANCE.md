## 真实点火与启动刷新边界

真实 A/B 点火会产生模型请求和少量额度消耗，只有用户再次明确授权后才允许执行。Codex 本轮没有点击点火或调用模型端点。

签名包冷启动测试会启动生产 App，正常启动路径可能执行已有账号或 Keychain 对应的只读刷新；当前命令记录不能证明是否实际取得凭证，因此该测试只作为窗口与进程清理证据，不计入真实 DeepSeek、Command Code 或 ChatGPT 数据验收。
