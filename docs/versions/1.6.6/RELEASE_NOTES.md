# Minget 1.6.6：Gemini 其他额度组直显、概览条与 Command Code 等长

Gemini 详情卡不再把官方返回的第二组额度折叠起来：`Claude and GPT models` 直接显示在主额度下方，保留组名，去掉「其他额度组」折叠控件，也不再显示「最近成功 hh:mm」与「缓存数据」整行。刷新与缓存状态继续显示在卡片标题栏右侧。

这一组的用量条与「剩余 %」改用 Claude 品牌橙 `#D97757`，剩余低于 20% 时仍为红色；重置时间条继续使用蓝色，不随用量颜色变化。主额度组、ChatGPT、概览与菜单栏的绿/橙/红分级保持不变。

概览页里 ChatGPT 与 Gemini 的额度条加长到与 Command Code 的双列一样长（两列各 106 pt）。名称列因此变窄：名称过长时会截断，下方状态小字会先缩小、再截断，完整内容仍可在悬停提示中查看。

本机独立完整回归 689 项，684 通过、5 项既有环境跳过、0 失败；Release 严格签名与正式安装版指纹核对通过。

正式安装版的 Gemini 三账号详情、概览布局、滚动与品牌只读刷新已由 Codex 现场检查。用户体验复验、真实低额度红档、VoiceOver 现场朗读与第二台 Mac 未全部执行，详细状态见 [验收台账](https://github.com/ym911x/Minget/blob/v1.6.6/docs/versions/1.6.6/ACCEPTANCE.md)。

发布独立回归首次有一个既有子进程测试未生成临时 PID 文件；随后针对性 11 项和完整 689 项复测全部通过。原失败及复测均保留在发布记录中。

继续源码分发；本机签名包仅用于本机验收，无自定义二进制附件。
