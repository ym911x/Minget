# 1.4.1 详情页外观与显示名称需求

状态：已实现、通过发布验收并发布。Release 构建、严格签名、真实签名应用界面和发布提交 CI 均已确认；`v1.4.1` GitHub Release 已公开。本版本只改变详情页、设置页中的显示层级和本地显示名称，不改变账号绑定、缓存、刷新、点火计划或网络接口。

## 1. 目标

- 保持 440 pt 宽、单列四张卡片。完整页面按内容增高；只有屏幕可用高度不足时，卡片区才使用一个垂直滚动区域。
- 将标题、额度、重置时间、摘要分成清晰的留白组，去掉卡片内横向和纵向分隔线。
- 版本号与“明明有数”同行，底部对齐。
- 标题使用 15 pt，额度标签和金额使用 12 pt，辅助信息使用 11 pt；长文本和大数值允许在所属区域换行。

## 2. 卡片规格

### 2.1 ChatGPT

- 头部第一行显示本地自定义名称、套餐和点火按钮；套餐后用绿点表示真实实时连接。
- 连接异常、缓存或未知状态保留明确文字；邮箱单独右对齐显示。
- 5 小时重置时间使用 5 格，周额度重置时间使用 7 格；额度条和时间条分开显示，时间条更细。
- 同一周期的额度和重置时间为一组，组内间距 4 pt，两个周期间距 10 pt，头部、额度区和摘要间距 12 pt。

### 2.2 DeepSeek

- 第一行显示自定义名称和真实余额；第二行保留 `deepseek` 品牌文字与连接绿点。
- 第二行右侧显示真实服务器状态：正常时为“服务器正常”，并保留官方状态页外链图标；异常状态按实际结果显示。
- 保留品牌标识和多币种事实，不合计、不换算、不补造余额。

### 2.3 Command Code

- 保持 5 小时、周、本月三条额度区。本月重置时间使用一整条连续进度条，文字采用 `24天 · 10-15` 格式并去掉“剩余”。
- “当前计费周期”下面固定两行：Token 行包含总 Token、输入、输出和总成本；请求行包含总请求、成功、失败和成功率。
- 统计字段缺失时显示 `—`，长内容只在所属统计组内续行。

## 3. 自定义名称

- 设置页为 ChatGPT A、ChatGPT B、DeepSeek、Command Code 分别提供输入、保存和恢复默认。
- 名称按稳定 Profile／服务 ID 写入本地 UserDefaults，去除首尾空白；空值恢复默认，最多 40 个字符，允许重名。
- 名称立即同步详情卡、设置页来源选择、点火计划名称和相关辅助功能标签。
- 菜单栏继续使用 A/B/DS 短标签；固定服务标识和 A/B 区分保留。

## 4. 边界与非目标

- 不读取或写入全局认证文件、Cookie、API Key、原始响应或 CLI 输出。
- 不新增提供方端点，不改变凭证、缓存、刷新、点火计划和网络白名单行为。
- 自动渲染和测试使用示例数据；不把示例数字写成真实账号验收结果。
