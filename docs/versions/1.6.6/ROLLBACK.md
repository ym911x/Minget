# 1.6.6 回滚

## 本机测试安装后的回滚（2026-10-10）

用户按已批准的计划授权在正式路径测试 1.6.6，`/Applications/Minget.app` 已由 1.6.5 替换为严格签名的 1.6.6。替换前的 1.6.5 完整备份：

`$HOME/Applications/Minget Backups/1.6.5-before-1.6.6-20261010-205126/Minget.app`

（备份内可执行文件 SHA-256 `dea70668cd3101d1d7207435f693547ebba887d17b0daf1e932dd27924b554a8`，与替换前的正式路径一致。）

回滚步骤：先正常退出 `/Applications/Minget.app` 并确认其自有子进程已回收，再把该备份包恢复到正式路径，然后执行 `codesign --verify --deep --strict /Applications/Minget.app`。个人目录兼容链接继续指向正式路径；不要直接运行备份。

备份只含应用包，不含 Key、浏览器会话或 CLI 认证文件。

## 本机状态

- 新增偏好键：无。本轮删除的 `expandedGoogleAccounts` 只是内存态（从未写入 UserDefaults），回滚到 1.6.5 不会读到本轮残留。
- 缓存与账号记录沿用 1.6.5 结构，未迁移、未清理；旧版本读到本轮产生的缓存无需转换。
- 界面改动只影响渲染：Gemini 卡片改用固定的组顺序显示，概览行图示变宽，都不写入磁盘。
