# 明明有数 · Minget 1.0.1

`1.0.1` 是首次对外公开的 Minget 品牌版本，核心功能继承自已通过用户实际验证的 `1.0.0`。

- 对外名称更新为“明明有数 · Minget”。
- 加入 M² App Icon、菜单栏标识和关于页面。
- 加入中文优先的双语公开文档、MIT License、安全说明和品牌权利说明。
- 工程内部 `UsageMonitor` 标识和 v1.0 历史归档保持兼容与真实。

当前应用包采用本机临时签名，尚未经过 Apple Developer ID 公证。GitHub Release 发布源码和构建说明，暂不提供面向普通用户的一键安装包。

## English

Version 1.0.1 is the first public release under the Minget brand. It retains the user-validated 1.0.0 feature set and adds the M² identity, app icon, About view, bilingual public documentation, MIT License, security guidance, and brand notice.

The current app bundle is ad-hoc signed and has not been notarized with Apple Developer ID. The GitHub release provides source code and build instructions rather than a general-user installer.
