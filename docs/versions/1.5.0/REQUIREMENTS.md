# v1.5.0 需求

目标：让首次使用者连接一个服务并看到真实额度；让已有用户在“全部显示”和“按供应商切换”之间选择；补齐详情页退出入口和菜单栏开关交互。保留当前菜单栏显示格式、四个既有来源及只读数据边界。

详情页默认全部显示。用户在设置中启用切换后，可选“全部、ChatGPT、DeepSeek、Command Code”；隐藏的供应商不出现标签，同一供应商的账号一起显示。选择按稳定标识持久化，失效时回到全部。切换不刷新、不改变菜单栏来源。底部管理账号、设置、退出始终可达。

首次安装自动打开可跳过的账号管理窗口；升级用户不强制引导。ChatGPT A/B 用各自隔离的 Codex app-server 完成官方浏览器登录，结束后读取身份和额度。DeepSeek 与 Command Code 使用现有 Keychain 保存及只读验证。保存成功、认证完成和实时额度到达分别显示，不把缓存或未知值当作实时。

同一时刻只有一个交互登录；登录时暂停该账号的冲突额度读取，取消时请求官方取消接口。通知只接受当前 ID 与连接代次。登录 URL、Key、原始 RPC 响应不写入日志、偏好或文档。不点火、不消耗重置权益。

不增加新供应商或代理功能。GitHub 发布需后续单独授权。
