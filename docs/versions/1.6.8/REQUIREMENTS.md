# 1.6.8 需求：菜单栏固定长度与账号代号

## 背景

菜单栏项目的宽度目前按内容实时测量：`78%` 与 `100%` 差一个字符、Gemini 的额度组名长短不一，宽度就跟着抖动。账号在菜单栏里只用 `A`/`B`/`G1` 这类内部短标签区分，与设置里「菜单栏显示」列表的名称没有一眼可对的对应关系。

## 需求

1. **长度固定**：菜单栏额度显示区域对所有来源、所有数值、所有异常状态都保持同一宽度，不再随内容变化。
2. **规范代号**：
   - ChatGPT（OpenAI）账号 → `O1`、`O2`、…
   - Gemini 账号 → `G1`、`G2`、`G3`、…
   - DeepSeek → `DS1`、…
   - 代号来自账号注册表的持久化序号；删除账号后剩余账号不重排。
3. **设置对应**：「菜单栏显示」列表中，每个候选名称左边加上同一代号，如 `O1 Codex 账号`、`G1 cn189 · Google`、`DS1 DeepSeek`。
4. **菜单栏内容**：上排显示「代号 + 百分比」（如 `O1 78% 42%`），下排仍是 5 小时与周额度的两条时间条，表达不变。

## 口径（已与用户确认）

- 上排统一为代号 + 两个百分比；`5H` / `W` 字样与 Gemini 额度组名不再出现在菜单栏。
- 所有来源共用一个固定宽度。
- DeepSeek 沿用现有大字显示；与固定宽度冲突时允许省略币种代码。
- 只保留一种宽度：刘海或空间不足时不再压缩，直接按既有逻辑打开独立详情窗口。
- Command Code 本轮不作为菜单栏来源，不引入新代号。

## 非目标

- 不改动取数逻辑、刷新策略、凭证处理与任何端点。
- 不改概览页、详情卡、菜单栏以外的任何界面。

## 验收要点

- 同一菜单栏项目在数值从 `9%` 变到 `100%`、从额度源切到 DeepSeek、出现缓存/失败标记时，长度不变。
- 设置列表与菜单栏显示同一代号。
- 完整回归 0 失败；渲染证据（明/暗）显示每个来源等宽。
