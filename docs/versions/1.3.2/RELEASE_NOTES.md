# Minget 1.3.2 发布说明

## 点火确认更省

- 点火后的两次确认只读取额度，不再附带账号身份请求。
- 卡片在结果后展示实测差值：`新窗口已确认 · +6小时12分`，小幅移动如 `+32秒` 也可见，59 秒与 61 秒的边界肉眼可辨。
- 每个账号保留最近 3 次点火记录，悬停结果即可查看；重启即清空，不写入磁盘。

## 每日点火计划

- 设置页可为 OpenAI 账号 A、账号 B 和 Command Code 分别添加多个每日时间，每条勾选后生效。
- 应用启动或睡眠唤醒错过时间时，最多补跑 10 分钟；同一条计划在同一天不会重复执行。
- 相邻已启用时间小于 5 小时时会提示，避免误以为每次都能开启新窗口。

## Command Code 也可点火

- Command Code 卡片新增「5 小时点火」。手动确认或启用定时计划后，Minget 使用 Keychain 中的 Key 通过官方 CLI 发起一次最小请求。
- CLI 不经 shell，禁用自动更新、session 和 skills，使用隔离的 `HOME`；输出不保存。定时点火不会弹出 Keychain 授权窗。
- 点火后只读 Command Code `credits` 确认窗口，并显示与 OpenAI 一致的三态、差值和最近 3 条历史。

## 刷新更省电

- 详情页时钟从每秒刷新降为每 30 秒；菜单栏倒计时不受影响。
- ChatGPT 定时轮询按重置时间动态退避：临近重置 30 秒，平时 120 秒，无数据时 60 秒。
- Command Code 统计与订阅分别按 API Key 的完整摘要隔离，15 分钟内独立复用；额度仍每轮读取，手动刷新和重连仍全量。
- 菜单栏宽度测量结果缓存，签名不变时不再重建测量视图。
- 睡眠唤醒后先用现有 app-server 探活并只读额度，只有失败的 Profile 才完整刷新；30 秒内不重复。

## 测试维护

- 修复辅助功能测试复用旧窗口列表的问题；相关注释按实测修正。

## 未变

卡片顺序、额度语义、菜单栏格式和点火三态真值表不变。Command Code 卡片、详情页与设置页因新控件增高。

## 验证

506 项自动测试执行：505 项通过、1 项跳过（XCTest 无可观测 AX 窗口）、0 失败。新增回归使用 fake CLI、fake Keychain 与 fake transport，不消耗真实额度；Release arm64 构建与严格签名通过，用户已确认真实 Command Code 手动点火成功。

真实睡眠/唤醒、完整界面和 Command Code 定时点火由用户接受移至发布后验证，不随发布改记为通过；真实 DeepSeek 菜单栏、A/B 真实点火与重启复验继续待用户验收。本发布继续只提供源码与构建说明，不附带未经 Apple Developer ID 公证的安装包。
