## 摘要

完成 Minget 1.6.0 Google 官方 Antigravity CLI 双账号登录与只读额度接入，并准备发布资料。包含此前尚未独立发布的 1.5.0 详情页与账号管理工作。

## 实现

- 固定官方 CLI 1.2.13，Google 官方下载、SHA-512 与签名校验。
- 两槽位独立 profile、规范邮箱确认、重复身份拒绝、失败重新登录保留原连接。
- 授权码仅短暂留在内存；PTY 输入、取消、超时、引导导航、TLS 环境及身份解析修复。
- 固定 `/usage` JSON 解析，缺失字段、真实零额度、共享组及重置时间按官方返回显示。
- 正式账号管理、卡片和菜单栏接线；缓存与任务隔离，旧请求结果不得回写。
- 迁移仅清理 Minget 自己的代理配置，不更改外部 CPA。
- 更新 README、CHANGELOG、版本资料，准备脱敏示例截图与 Release 文案。
