# 1.6.3 审核

状态：代码复核、完整回归、Release 严格签名、本机备份安装和入口检查通过。真实新账号登录/取数、真实移除及新账号点火保留待验收；本轮未公开发布。

## 复核结论

- 稳定账号 ID 和平台/添加顺序统一来自注册表；取消草稿不持久化，损坏注册表失败关闭。旧 Profile 目录与 ID 严格绑定，Google UUID/身份不允许重复，API 凭证引用按实例校验，名称在写 Key 前校验。
- API 新实例不复用仅按平台的引擎和缓存。凭证世代失效仍由既有 reader/engine 控制；迟到响应在替换和删除期间不得回写，测试验证其他实例不变。
- Google 没有读取 CLI 认证文件；ChatGPT 使用官方 app-server 登出，Key 不进入注册表。网络白名单与跨域重定向策略沿用。没有新增模型 HTTP 端点。
- 删除停止状态先落盘，失败重试保持停止；计划及菜单栏 tombstone 只处理目标 ID。假登出验证目标缓存清理及失败保留，假 Keychain 验证删除失败可恢复。
- 点火按账号隔离，Command Code 串行，新增默认关闭；测试只用假 CLI，真实界面未点击点火。外部脚本及 LaunchAgent 不在本轮变更内。
- 动态列表复用 1.6.2 样式，窗口按数量与屏幕上限计算，切换服务保留窗口，添加固定在账号页顶部。旧布局、刷新、启动和退出检查纳入完整回归。

## 新增 Google 账号现场反馈

接续初版审核，发现官方 `status=ERROR` 的地区资格拒绝被通用退出错误覆盖，以及无快照被标记缓存。已补固定类别和快照条件，详见 [诊断与修正](GOOGLE_ELIGIBILITY_FIX.md)。目标账号的地区资格仍需用户按官方流程核对，不宣称取得其额度。

本轮复核确认新分类必须匹配 ERROR 及两段明确地区资格文案，固定显示文字不透传错误。无数据缓存展示由快照存在性约束，账号隔离/重启回归通过。658 项完整回归与严格签名安装通过；正式完整路径账号页和详情现场验收通过，原两个 Google 连接成功刷新。第三账号真实额度未通过，其服务端资格需用户核对。
