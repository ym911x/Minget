## 4. 详情页规格

### 4.1 窗口与标题

采用原生 SwiftUI/AppKit，支持现有 macOS 13 最低版本。浅色参考图为视觉基准，深色使用对应系统语义色。不得使用整张生成图片作为界面背景，也不照搬生成图中的桌面菜单栏。

初始建议宽 420 pt，内容高度按可见平台动态取 300、370、400 或 475 pt，最终仍按真实字体测量调整，不能直接按图片像素或沿用旧 320 pt 导致压缩。外边距 16 pt、卡片间距 12 pt、内边距约 16 pt、圆角约 12 pt；详情弹层锚定到菜单栏按钮的水平中心，背景沿用系统外观。

顶部一行：左侧显示产品名称和版本号。名称跟随系统首选语言，在中文环境显示“明明有数”，在英文环境显示 `Minget`；版本号始终以小字显示在名称下方。右侧可点击刷新图标及更新状态，最右侧齿轮。标题下无软件账号邮箱。刷新调用现有 refreshNow，刷新期间禁用重复点击并显示“刷新中…”。齿轮打开或聚焦唯一设置窗口。

更新状态必须真实：针对当前可见且已配置的平台，全部有有效成功数据时，以最早的成功时间表示共同新鲜度；存在缓存或失败时显示“部分数据未更新”，具体卡片保留错误状态。首次未获取显示“等待更新”。未配置平台不计入共同成功时间。不能以最近一个平台成功掩盖另一个平台失败。刷新行为仍覆盖原有服务集合，不因为隐藏而改变后台轮询或认证暂停策略。

### 4.2 Codex 卡片

第一行：使用 OpenAI 官方 Blossom 图标，图标后显示 `account/read` 返回的套餐类型，例如 `plus` 或 `5xPro`；最右侧是实际 Codex 邮箱。长邮箱中间截断，悬停和辅助功能可读取完整值；缺失时显示“账号暂不可用”，套餐缺失时显示“套餐暂不可用”，不得硬编码截图邮箱或套餐。

其余四行使用同一个三列布局：左标签、固定宽度条、右侧数值。两列文字宽度由最长标签及日期测量确定，四条轨道共用同一宽度与坐标，不允许每行独立 Spacer 分配。

| 行 | 左侧 | 中间 | 右侧 |
| --- | --- | --- | --- |
| 1 | 5 小时 | 连续额度条 | 剩余 97%（真实值） |
| 2 | 重置时间 | 蓝色 5 段时间条 | MM-dd HH:mm |
| 3 | 周额度 | 连续额度条 | 剩余 14%（真实值） |
| 4 | 重置时间 | 蓝色 7 段时间条 | MM-dd HH:mm |

四条轨道左右端完全对齐，总长度一致。时间条的总长度包含段间隙，每段长度为 `(总宽度 - 间隙 × (段数 - 1)) / 段数`。额度轨道建议高 8 pt，时间轨道建议高 6 pt、间隙 3 pt；保持截图中清晰可数的圆角短线。

额度使用现有阈值与绿/橙/红语义，不从旧设置图引入新的 20% 阈值。空轨道统一浅灰，深色使用对应语义灰。额度 0% 必须无彩色填充，100% 满格；修正现有最小 4 pt 填充若导致 0% 仍显彩色的问题。

时间条蓝色统一，不随额度颜色变化。5 段各表示 1 小时，7 段各表示 1 天；依赖真实 resetsAt 与同一 now，复用 ResetTimeModel，左侧填充、右侧先退、允许部分段。沿用现有本地计时刷新，禁止新增每秒网络请求。

重置点按系统时区显示 `MM-dd HH:mm`，完整日期与时区可在悬停和辅助功能中显示；不再显示倒计时或时间百分比。到期条为空并提示“等待刷新”，未知显示“时间未知”，非法时间显示“时间不可用”，不得空条配虚构日期。到期后不得在本地自动满格。缓存数据应标明“缓存”，不能伪装实时。

### 4.3 余额卡片

DeepSeek、智谱 GLM 及后续接入的平台各自占据一整行，不再使用两栏并排。平台标识、名称、简短连接状态和醒目余额保持同一行的主次关系。图标必须来自可追溯且可用的资源，记录来源；不能将生成图里的仿制图标当官方素材。缺少可靠资源时用简洁文字标识占位并记录待验收项。

金额优先 available，否则 total。DeepSeek 现有模型只有 total，标签用“余额”；GLM 有 available 时用“可用余额”，否则用“余额”。此处按真实字段修正示意图文案，禁止为匹配图片修改 Provider 映射。

概览固定两位小数，Decimal 十进制舍入，禁止转 Double 后格式化；正数不足 0.01 显示“< ¥0.01”（其他币种保留币种标识），避免显示成真实零。CNY 使用 ¥，其他币种保留明确代码，不合并不同币种。多币种逐项呈现，允许卡片增高；完整精度与原有明细放设置中的连接管理折叠区，不增加精度偏好。

连接成功显示简短“已连接”。未连接显示“未连接”和“前往设置”；需要授权/重新登录给出相应入口，直达设置中的该服务。请求失败但有缓存保留缓存值及标记；无数据显示不可用，不能显示零。正常成功反馈在设置内呈现，不让“余额已验证”等文字长期占据概览。

DeepSeek 卡片在顶部元数据区以小号文字和一个状态圆点显示连接状态、当天整体服务状态及“状态页”入口，不再增加独立的状态行或分隔区。该摘要只读取 `https://status.deepseek.com/` 的公开页面，页面不可达或标题无法识别时显示“状态暂不可用”，禁止推断为正常。DeepSeek 使用用户提供的黑色鲸鱼图标和去除“开放平台”字样的透明 `deepseek` 文字标识；OpenAI 使用 `/Users/yuyimeng/Downloads/OpenAI-logos/SVGs/` 中的原始 Blossom SVG，并保留 PNG 作为回退，两个提供方的可见图形左边界和视觉尺寸保持一致。

每个可见平台占满整行；两者关闭则移除余额区域并缩短弹窗，不留空白占位。正常单币种状态无滚动；异常长文、多币种、辅助功能字号或屏幕空间不足可有高度受限的滚动兜底。

## 5. 精简设置窗口

单窗口、单页、无侧栏、无四分类导航。宽 440 pt，默认高 420 pt；默认内容直接完整展示，不使用滚动容器。页首“设置”，主要内容如下：

| 内容 | 操作 |
| --- | --- |
| DeepSeek：状态 | 在详情页显示开关；管理 |
| 智谱 GLM：状态 | 在详情页显示开关；管理 |
| 高级诊断（默认折叠） | 迁入已有钥匙串诊断开关、日志路径、GLM 脱敏诊断 |
| 底部 | 实际版本、关于、打开详情窗口、退出 |

显示开关即时保存到应用自有 UserDefaults，建议键 `detail.showDeepSeek`、`detail.showGLM`，缺省为 true；单纯开关不得读写 Keychain、断开连接、清缓存或新增请求。隐藏后仍可在设置管理服务，重新开启立即使用已有状态。

点击管理在同页展开对应连接区，一次最多展开一项；折叠/切换不得因后台刷新丢失输入草稿。关闭设置窗口时不自动保存未提交 Key。

DeepSeek 复用 SecureField、保存验证、删除 Key、授权读取反馈；智谱复用独立控制台登录、重新连接、断开与官方控制台入口。GLM 未经真实验证的 API Key 兼容入口不放普通管理页，现有探测/兼容诊断如保留则收纳高级诊断，不新增后台行为。断开或删除凭证须明确确认目标，失败不得冒充成功或清空现有 UI 状态。

诊断保留用户既有开关值，不因迁移改变记录状态；默认折叠仅影响可见性。不新增日志导出、清理、通知等控件。
