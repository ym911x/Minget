# Minget 1.6.7：设置窗口视觉统一

设置窗口按 macOS 系统设置的样子重排，功能和开关没有任何变化。

每个页面现在只有一处标题和一行说明；原先重复的分组小标题被去掉，说明文字放在所属分组的下面。成对的「标签 + 控件」对齐成两列，阈值行改为先显示「低于 N%」再用步进器调整。

左侧导航的五个条目改成彩色圆角图标：账号（蓝）、菜单栏（靛蓝）、详情显示（青）、刷新与点火（橙）、关于与诊断（灰），选中时保持彩色并沿用系统高亮。

「账号」页把标题和「添加账号」移到页头，账户行统一为分组内的整行（服务图标、名称、身份、状态、右侧操作），不再出现卡片套卡片。点火计划以分组标题呈现，并补齐了开关与时间选择的辅助功能名称。

「关于与诊断」补上了品牌语与诊断范围说明；在没有应用版本信息的环境里，版本显示为 `—`，不再显示过时的假版本号。

本机独立完整回归 694 项，689 通过、5 项既有环境跳过、0 失败；Release 严格签名与正式安装版指纹核对通过。

验证边界：观感验收由用户进行，状态见 [验收台账](ACCEPTANCE.md)；VoiceOver 现场朗读与第二台 Mac 未执行。本轮未发布，继续在正式路径使用本机签名包。
