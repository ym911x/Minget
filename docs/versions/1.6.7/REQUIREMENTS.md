# 1.6.7 需求：设置窗口视觉与信息层级统一

用户反馈：「明明有数设置」窗口虽然功能齐全，但观感简陋，与本应用的详情页、概览页非常格格不入，希望在不改功能的前提下把美观做上去。

## 已确认的口径

| 决定点 | 结论 |
| --- | --- |
| 视觉风格 | 系统原生设置风：贴合 macOS 系统设置的观感（分组卡片、清晰的分组标题、标签与控件成列对齐） |
| 侧栏图标 | 彩色：每个导航项一枚带色圆角方块图标（系统设置同款语言），浅色/深色自动适配 |
| 账号页 | 一起改：账户行统一到同一套排印与间距语言 |

## 现状问题（实施前已在源码中逐条确认）

1. 详情栏存在三层重复标题：页面标题（18 pt）→ 分组标题（`Section`）→ 分组内部小标题（「菜单栏显示」「5 小时点火计划」「管理你的账号」）。同一件事说三遍。
2. 说明文字被塞进独立 Section（如「概览显示所有账号摘要…」独占一张卡片），原生做法是分组 footer。
3. 字号散落硬编码（11/12/13 pt 混用），未利用原生表单排印；手工 `HStack { Text; Spacer(); 控件 }` 使标签与控件左右不齐。
4. 侧栏是系统强调色单色 SF Symbol，五个条目区分度低。
5. 账号页把标题、说明、主操作挤在自绘 VStack 里，与页面标题重复，主操作（添加账号）不在可预期位置。

## 视觉口径

- 侧栏图标配色使用系统语义色（蓝=身份、靛蓝=菜单栏、青=展示、橙=刷新与点火、灰=信息），不新增自造品牌色；Claude 橙 `#D97757` 继续只表示 Claude 与 GPT 模型额度池，不挪作界面底色。
- 页面标题 20 pt semibold，配一行 11 pt 次要说明；每个分组只保留一处标题，具体提醒放在该分组 footer。
- 分组卡片本身即容器：不在分组卡片内再套卡片，账户行按原生整行（图标 + 名称 + 身份 + 状态 + 尾部动作）显示。
- 成对的「标签 + 控件」行使用 `LabeledContent`，标签与控件对齐成两列。
- 字号、留白、侧栏方块尺寸收敛为设置页自己的少量常量，不再散落魔法数字。

## 边界

- 只改视觉与信息层级：不改任何开关语义、持久化键、取数、节流、缓存、凭证、点火与菜单栏行为。
- 不引入第三方字体、图标库或新资源文件；不改变窗口尺寸与最小尺寸。
- 本轮只完成编码、自动验证、签名构建与本机安装；不发标签、不推送、不建 Release，除非用户明确要求。
