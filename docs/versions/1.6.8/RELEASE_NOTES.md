# Minget 1.6.8：菜单栏固定长度与账号代号

菜单栏项目的长度现在固定了：不管剩余量是 9% 还是 100%、切换哪个账号、有没有「缓存/读取失败」标记，长度都不再变化。

菜单栏上排改成「代号 + 百分比」，例如 `O1 78% 42%`、`G1 80% 90%`。`5H` / `W` 字样和 Gemini 的额度组名不再出现在菜单栏（额度组仍在设置里选择）。下排的 5 小时与周额度时间条表达不变。

固定宽度的计算方式：宽度等于菜单栏能显示的最宽配额文案——两个 100% 加两位代号（`O1 100% 100%`）——再加 2 pt 取整余量，项目总宽 93 pt（之前的实现是 123 pt，多出来的空白已去掉）。缓存或失败时的警示标记与文字同行，不再额外占位，长度依旧不变。

账号代号统一了：ChatGPT（OpenAI）是 `O1`、`O2`…，Gemini 是 `G1`、`G2`、`G3`…，DeepSeek 是 `DS1`、`DS2`…。代号取自账号本身的序号，改名字或删掉别的账号都不会变号。设置里「菜单栏显示」列表的每一行左边就是这个代号（`O1 Codex 账号`、`G1 Google 账号`、`DS1 DeepSeek`），和菜单栏显示的一定对得上。

DeepSeek 仍是 13 pt 大字余额行；固定宽度下币种代码按约定省略，显示 `DS1 123.45`（金额不会截断，位数太多时整行略微缩小字号）。

被刘海遮挡或空间不足时不再缩小内容，而是直接打开独立详情窗口，不显示残缺文字。

本机独立完整回归 693 项，688 通过、5 项既有环境跳过、0 失败；Release 严格签名与正式安装版指纹核对通过。

本次也包含此前未单独发布的 1.6.7 设置窗口视觉统一：macOS 系统设置风格、彩色侧栏图标、统一账号行，以及更清晰的分组说明和控件对齐。

正式安装版已由用户复验通过。刘海机型现场表现、VoiceOver 现场朗读与第二台 Mac 未执行，状态见 [验收台账](https://github.com/ym911x/Minget/blob/v1.6.8/docs/versions/1.6.8/ACCEPTANCE.md)。
