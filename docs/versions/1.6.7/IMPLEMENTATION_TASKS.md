# 1.6.7 实施任务

开发入口：主目录分支 `codex/minget-1-6-7`，起点为干净 `main` 的 `1592f46`（1.6.6 发布台账回写提交）。

1. 新增设置页样式常量 `SettingsStyle`（标题字号、页面留白、页头上下留白、说明字号、侧栏方块尺寸/圆角/字形），替代散落的硬编码。
2. `SettingsSection` 增加 `subtitle`（每个分组一行说明，供页头使用），并在视图层增加 `tint`（系统语义色）。
3. 侧栏：`Label` 换成自绘行，彩色圆角方块（22×22、圆角 6、白色 12 pt 符号）；选中沿用 `List(selection:)` 原生高亮；图标对辅助功能隐藏，行保留标题。
4. 详情栏统一页头：标题 20 pt semibold + 一行 11 pt 次要说明 + 可选尾部主操作（账号页的「添加账号」）。
5. 菜单栏分组：删除内部重复小标题，说明改入分组 footer；Google 额度说明并入相应 footer。
6. 详情显示分组：说明从独立 Section 移到该分组的 footer。
7. 刷新与点火分组：成对行改用 `LabeledContent` 对齐；阈值与错误提示归位到一致的层次。
8. 点火分组：以 `Section("5 小时点火计划")` 作分组标题，删除 `FireScheduleSettingsView` 内部的重复标题。
9. 关于与诊断：版本行等用 `LabeledContent` + `monospacedDigit`；`appVersion` 在缺少 bundle 元数据时返回 `—`，不再回退成过时的假版本号。
10. 账号页（托管与旧路径）：标题与主操作移入页头，删除自绘标题块；账户行统一样式与分隔，不在分组卡片内嵌套卡片。
11. 新增自动测试：分组说明非空且互不重复、每个分组的 SF Symbol 可解析、样式常量关系、版本回退值。
12. 导出五个分组的明暗渲染证据并逐张目视核对（彩色图标、单一标题、footer 说明、控件列对齐）。
13. 版本号升到 1.6.7，更新变更记录、版本索引、项目状态与版本目录资料（需求、任务、实施记录、审核、验收、回滚、发布说明、证据）。
14. 运行完整 `swift test` 与 Release 严格签名构建，备份并安装到正式路径，记录回滚指令。
