# 明明有数 · Minget 1.3.1

1.3.1 是基于 1.3.0 的稳定性修补版。窗口尺寸、卡片顺序、菜单栏格式和凭证安全边界保持不变。

## 本次更新

- 两个 ChatGPT Profile 继续并行刷新，任一 Profile 完成后立即发布自己的状态，快速账号不再等待较慢账号；卡片顺序仍固定为账号 A、账号 B。
- 点火结果细分为“新窗口已确认”“请求成功，窗口未变化”和“请求成功，暂无法确认”。第一次只读确认没有得出结论时，5 秒后再读取一次额度，不会重复模型请求。
- Command Code 以 `credits` 为必须主数据，`summary` 和 `subscriptions` 为可选辅助数据。辅助接口失败不再遮住已经取得的 5 小时、周和月度余额。
- Command Code 缓存状态明确显示 `<套餐名> · 缓存` 或“缓存数据”，帮助文本给出最后成功时间；缺少统计时显示“统计暂不可用”，不会伪造金额、周期或统计数字。
- 修复 Command Code 无用量状态下的辅助功能结构：Logo、标题和状态文案组合朗读，“前往设置／查看设置”保留为独立、具名且可激活的元素。

## 验证

- 全量自动测试：Core 331 项、App 120 项，共 451 项执行，450 项通过、1 项明确跳过、0 项失败。
- 跳过项为 XCTest 进程中的真实 AX 树检查；该进程没有可观测的辅助功能窗口，未把跳过记为通过。
- Codex 另用当前源码编译临时 GUI harness，真实系统 AX 树返回独立的 `Command Code` 身份元素和“前往设置”入口；执行 `AXPress` 成功并触发产品动作。
- Release 构建、版本 1.3.1、staging 与固定运行路径严格签名验证通过。
- 浅色和深色脱敏渲染已检查，正常、缓存、统计不可用、周期未知及无用量状态没有发现可见截断。
