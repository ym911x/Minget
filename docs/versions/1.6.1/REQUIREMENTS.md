# 1.6.1 需求

用户确认：概览＋服务详情；设置与账号管理共用原生设置窗口；Gemini 默认主组、展开其他官方共享组；GPT/Gemini 百分比统一两位小数。

- 概览集中显示六个来源的摘要，完整轨道、重置时间与点火留在服务详情。保持 440 pt 单列，640 pt 高度上限及短屏限制，只有内容区滚动。
- 顶部原生服务选择器与刷新，底部管理账号、设置、更多菜单；点火放卡片底部，继续人工确认。
- 系统字体、语义颜色、16 pt 内边距、12 pt 卡片留白；GPT/Gemini 共用额度与重置双轨，周期不补造。
- 设置采用侧栏＋原生 grouped Form，账号、菜单栏、详情显示、刷新与点火、关于与诊断统一。账号行和编辑 sheet 共用，登录与额度状态分开。
- 不改变取数协议、额度计算、身份归属、菜单栏来源、认证、刷新和点火授权边界。
- 主目录、工作区、当前文档及历史证据归位；不推送或公开发布。
