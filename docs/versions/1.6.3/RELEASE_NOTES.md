# 明明有数 · Minget 1.6.3：多账号添加与完整概要

- 账号管理顶部、四个平台分组及服务详情提供添加入口。支持第三个及更多 ChatGPT、Google 账号，以及多个 DeepSeek、Command Code 连接。
- 各账号独立命名、重新连接、刷新和确认移除；现有账号、隔离目录、Keychain 条目、名称、菜单栏来源、缓存及点火计划沿用。新增账号点火计划默认关闭。
- 概要按账号数量增高，当前七账号及底部操作完整可见，屏幕容纳时无需滚动；平台详情继续滚动，超出实际屏幕高度时保留滚动兜底。
- Google 官方地区资格拒绝显示具体原因及官方说明，无成功额度时不再显示缓存标记。
- 刷新、API 凭证、缓存、点火及移除按账号隔离；替换凭证或移除后的旧响应不能覆盖其他账号或恢复已移除账号。

本机完整回归 660 项：655 通过、5 项既有环境跳过、0 失败。Release 严格签名、备份安装和真实窗口检查通过，用户已确认概要显示并授权发布。第三个 Google 账号仍因官方地区资格受限而无法读取额度，其他真实新增账号及移除/点火场景的待验收状态见验收台账。
