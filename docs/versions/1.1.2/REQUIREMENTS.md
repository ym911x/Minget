# 1.1.2 需求

日期：2026-09-14

## 目标

1. 修复菜单栏偶发只显示 `5H`、周额度和时间条消失的问题。
2. 在 OpenAI 详情卡显示 app-server 返回的可用 earned rate-limit reset 信息。
3. 调整 DeepSeek 详情卡层级，保留现有真实余额和官方状态读取边界，并移除没有账号信息时的空白占位。
4. 详情页直接显示完整内容，不出现纵向滚动条。

## 明确行为

- 菜单栏生产模式只有完整和紧凑两种，紧凑模式仍显示 5 小时额度、周额度和两排时间条。
- OpenAI 重置摘要显示可用次数；服务提供有效明细时追加最近到期时间。只读，不消费权益。
- OpenAI 重置摘要缺失、非法或来自缓存时显示“重置信息暂不可用”，不显示伪造的 0。
- DeepSeek 顶部保留鲸鱼 Logo，右侧显示现有 DeepSeek 文字标识；真实余额与品牌同列靠右并垂直居中，连接状态和官方服务状态位于 Logo 下方。
- 详情页为固定整页布局，窗口按当前是否显示 DeepSeek 预留完整高度，不依赖滚动容器承载内容。
- DeepSeek 不新增未经确认的账号接口，不读取浏览器会话，不以 API Key 指纹代替账号名称。

## 不包含

- 不实现重置消费按钮、确认流程或 `account/rateLimitResetCredit/consume`。
- 不新增 DeepSeek `/user/info` 或其他账号接口。
- 不修改 Keychain、认证文件、远端仓库、标签或 Release。

说明：以上“不修改远端仓库、标签或 Release”是实现范围边界。实现验收完成后，发布动作按用户单独授权执行，不改变本版本的运行时和凭证处理边界。
