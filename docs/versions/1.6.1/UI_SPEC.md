# 1.6.1 界面规范

- 详情页宽 440 pt，内容区 408 pt，边距 16 pt，行距 12 pt，高度最多 640 pt并受屏幕可见区约束。概览每账号 64 pt，六个来源时 608 pt。
- 顶部：产品名与版本、刷新；第二行：返回概览、原生服务菜单、聚合更新状态。底部固定管理账号、设置与更多菜单。
- 概览只保留名称、连接/更新状态、主额度摘要；完整额度进入服务详情。GPT/Gemini 卡片共用头部、13 pt 额度文案、11 pt 辅助文案、两位小数与语义颜色。
- 额度轨道与重置轨道分开。5 小时为 5 段，周为 7 段；显示真实绝对时间，到期等待读取。缺失百分比为空轨道及“—”，已知时间仍保留；不自行补满或创造周期。
- Gemini 首选官方 Gemini Models 主组，其他共享组展开查看；主组缺失不替换成其他共享池。展开状态随账号保持，刷新及服务切换不丢失。
- ChatGPT 与 Command Code 点火统一放卡片右下角，原确认文案及授权语义保留。
- 设置使用原生 NavigationSplitView＋grouped Form，默认 780×640 pt，最小 700×520 pt。账号、菜单栏、详情显示、刷新与点火、关于与诊断分栏。
- 账号行共用品牌标识、名称、身份、状态与右侧主操作/更多菜单；API 管理及名称编辑使用 sheet。连接准备折叠，不占用正常账号操作行。

生产视图示例图使用隔离账号与合成数据；真实应用检查另记 ACCEPTANCE，不能互相替代。
